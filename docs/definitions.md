# Definitions

This file is the single source for the bracketed definitions shown by the `<Term>` component (`src/components/Term.jsx`). The app reads this table at build time, so an edit here changes every page that uses the term.

How to edit:

- Change only the Definition column. The Term column must match the term in the code exactly (case does not matter).
- Do not use the `|` character inside a definition.
- Leave a definition blank to show the term on its own, with no brackets.
- To define a new term, add a row here, then wrap the term in the page with `<Term name="...">`.
